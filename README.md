# Responsive Web Portfolio 🚀

A dark-themed personal portfolio website featuring interactive canvas graphics, micro-animations, and a space-inspired aesthetic. Built with vanilla web technologies.

---

## ✨ Features

- **Shooting Stars & Starfield** — Full-viewport HTML5 Canvas particle background with randomized shooting stars.
- **Interactive 3D Butterflies** — WebGL particle simulation with cursor repulsion inside the contact card.
- **Celestial Constellation** — Interactive orbiting star nodes with hover tooltips around the hero avatar.
- **Launch to Top Rocket** — Animated back-to-top button with fueling animations and scroll progress indicator.
- **Projects Showcase** — Touch-enabled carousel powered by Swiper.js.
- **Responsive Layout** — Mobile-first design optimized across desktop, tablet, and mobile screens.
- **Zero Build Setup** — Pure vanilla code without bundlers, compilers, or heavy frameworks.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic markup, accessibility, and SEO structure
- **CSS3** — Custom properties, CSS Grid/Flexbox, glassmorphism, and animations
- **JavaScript (ES6+)** — DOM manipulation, Canvas API, and WebGL
- **Swiper.js** — Lightweight carousel library

## 🚀 Getting Started

No build tools or package managers required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mclejos/responsive-port.git
   ```

2. **Run locally:**
   - Open `index.html` directly in any web browser, or
   - Right-click `index.html` in VS Code and select **"Open with Live Server"**.
